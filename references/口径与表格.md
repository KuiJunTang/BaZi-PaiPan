# 口径与表格

本文件是内核取值的**唯一说明处**（single source of truth）。`docs/需求文档.md`、`docs/项目备忘录.md`、
`HANDOFF.md` 中的历法口径一律以此为准，不得各写一套。

凡改表或改口径，必改此处，并重跑 `validate_core.py`、`validate_ancient.py`、`verify_lunar.py`、
`verify_js.py 300`、`verify_independent.py 600` 与 `check.py`。

> 最后核对：2026-11-02（与代码逐项对过：`bazi_core.py`、`assets/data.js`、`assets/app.js`）。

## 一、历法口径

| 项 | 取值 | 说明 |
| --- | --- | --- |
| 时区 | 北京时间 UTC+8 | 不溯 1986–1991 夏令时；如需，先自行换算再入参 |
| 支持年份 | **公元 600–2100**（隋至清） | 600 年为隋·开皇二十年，非唐；输入上下限由年份下拉与 `--now` 共同约束 |
| 节气 | 1900–2112 查表（分钟精度，表尾 2112 含）；600–1899 与 **2113 起**走 Meeus 太阳视黄经回推 | 表由 `build_jsdata.py`／`build_jieqi.py` 自 sxtwl（寿星天文历，MIT）生成；表尾延至 2112，供 2090 年代出生者算交运；回推含 ΔT 修正，精度约 ±15 分钟 |
| ΔT | Espenak–Meeus 多项式 | 天文学时 TT 与 UT 之差；600 年约 +45 分钟，不减会使交节整体偏晚、月柱错一日 |
| 历法 | 1582-10-15 起格里历，之前儒略历 | 与 sxtwl 的日期体系一致；输入古代日期时须按儒略历书写 |
| 农历（**数据**） | **600–2100**（1501 年，`data.js` 内 `ln:{y0:600,y1:2100,base:1940228}`） | 由 sxtwl 生成；`base` 为 600 年正月初一的儒略日。**689–700、761–762 共 14 年**因 sxtwl 年边界错位，段内月日为近似（年份与年号仍正确，且不污染其他年份） |
| 农历（**录入**） | **仅 1900–2100** | 古代行用《麟德历》《大衍历》等，朔望与今不同，故只供显示、不作输入；超界点「农历」会提示并回退公历（`setMode` 判据） |
| 年号纪年 | **仅显示**，不作输入 | 元信息行：1900 年前显「纪年 朝代·年号年数 农历月日 时辰」；1900–1911 仍用农历年；1912–1949 显「民国X年」；1950 起用农历年。年号表 `ERAS` 自隋·开皇元年（581）起；流年年号与元信息行同口径，**≤1949 才显** |
| 年柱 | 立春交节时刻换年 | 立春前属上一年 |
| 月柱 | 十二节交节时刻换月 | 立春→寅、惊蛰→卯、清明→辰、立夏→巳、芒种→午、小暑→未、立秋→申、白露→酉、寒露→戌、立冬→亥、大雪→子、小寒→丑 |
| 月干 | 五虎遁（甲己之年丙作首） | `干 = (年干×2 + 2 + 月序) mod 10` |
| 日柱 | 儒略日 `(JDN + 49) mod 60` | 1900-01-01～2100-12-31 逐日与 sxtwl 比对，0 错 |
| 日界 | **子时换日：23:00 起即算次日** | 当日 00:00–00:59 仍属当日；`--no-late-zi` 可改回 00:00 换日 |
| 时柱 | 五鼠遁（甲己还加甲） | 子时干 = `(日干 mod 5) × 2` |
| 时辰划分（固定口径，默认） | 真太阳时/北京时间按钟点切分：23-1 子、1-3 丑…… | 不勾真太阳时或未给纬度时用 |
| 时辰划分（**古法**，勾真太阳时且给纬度） | **日出定卯初、日落定酉初，昼弧/夜弧各六等分** | 昼＝卯辰巳午未申、夜＝酉戌亥子丑寅；午初恒落真太阳正午、子初恒落真太阳子夜；日界＝真太阳子夜（此时 `--no-late-zi` 不参与） |
| 日出日落 | 太阳上边缘 h0=−0.833°（含蒙气差与视半径）；赤纬 sinδ=sinε·sinλ，λ 取当日 AST 正午视黄经（与节气同套 `_lon`/`sunLon`） | 纬度取政府驻地约值（`build_cities_lat.py` 自 github.com/88250/city-geo 生成，BD-09 坐标误差 <3 秒忽略）；手动可填「北纬」框 |
| 均时差 | **Meeus 28.1 天文法**：E=L0−0.0057183−α+Δψ·cosε，T 取 TT（含 ΔT） | 与节气回推同一套太阳视黄经，古今自洽；8 个天文年历锚点 ≤0.12 分；旧 Spencer 现代近似式在唐代偏差达 2.8 分，已弃用 |
| 真太阳时 | 北京时间 ＋ 经度差 × 4 分 ＋ 均时差 | 均时差一律用上行的 **Meeus 28.1**；旧 Spencer 式与 `9.87sin2B − 7.53cosB − 1.5sinB` 简化式**均已弃用**（唐代偏差可达 2.8 分，且与本行容易写成两套） |

## 五、大运与起运

- 顺逆：阳年男、阴年女顺行；阴年男、阳年女逆行。
- 起运时长：顺行取「出生→下一节」，逆行取「上一节→出生」。
- 折算：**3 日 = 1 年，1 日 = 4 月，1 月 = 30 日，1 日 = 24 小时**（逐级取整，与本盘截图口径一致）。
- 交运时刻 = 出生时刻 + 折算时长（按日历年月日相加）。
- 交运描述：「逢某年某节后 N 天」，N = 交运日与节气日的日期差。
- 大运干支：自月柱起，顺行加一、逆行减一，**共十二步**（运前另计，界面共 13 列，可横拖）；虚岁 = 交运年 − 出生年 + 1。
- 流年：取当前大运所辖十年（`ln` 恰 10 项），当年高亮。
- **运前**：只列出生年至起运前一年的流年，起运之后留空（道长第九令）；主盘大运列在运前显示「运前」。
